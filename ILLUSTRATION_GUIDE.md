# Where to add your illustrations

Place all images in the same folder as index.html. Keep the filenames below so the game finds them automatically.

## Main page

| Filename | Where it appears | Recommended format |
|---|---|---|
| hero-background.png | Full background of the opening screen | 1920×1080 or larger, 16:9, no text |
| mia.png | Mia on the right side of the hero section | PNG/WebP with transparent background |
| mines-cover.png | Grammar Mines card | 1600×900, 16:9 |
| race-cover.png | Word Road card | 1600×900, 16:9 |
| hidden-cover.png | Hidden Grammar card | 1600×900, 16:9 |

## Grammar Mines

| Filename | Where it appears |
|---|---|
| mines-game-background.png | Behind the 8×8 board |
| mine-tile.png | Optional custom closed tile |
| mine-bomb.png | Optional bomb image |
| mine-flag.png | Optional flag image |

The background should have a quiet centre because the HTML grid is placed over it.

## Word Road

| Filename | Where it appears |
|---|---|
| race-game-background.png | Behind the three lanes |
| mia-car.png | Optional replacement for the CSS car |
| road-cone.png | Optional obstacle |
| compass-bonus.png | Optional bonus |

Use a forward road perspective with exactly three clear lanes.

## Hidden Grammar

| Filename | Where it appears |
|---|---|
| hidden-scene-1.png | Lake Drivyaty Shore |
| hidden-scene-2.png | Castle Hill |
| hidden-scene-3.png | National Park Camp |
| objects.png | Optional transparent sprite sheet for the 24 objects |
| scarf.png | Clickable scarf in scene 1 |
| spoon.png | Clickable wooden spoon in scene 1 |
| rope.png | Clickable rope in scene 2 |
| whistle.png | Clickable whistle in scene 3 |

Each hidden-object scene should be 16:9 and must not contain text. Leave several visually clear areas for clickable objects.

## Important

- Do not put game titles or buttons inside the pictures; HTML adds them.
- Use PNG/WebP for transparent characters and objects.
- Use WebP or optimized JPEG/PNG for large backgrounds.
- Keep Mia’s face, braid, teal jacket, coral hoodie, navy trousers and yellow backpack consistent.
