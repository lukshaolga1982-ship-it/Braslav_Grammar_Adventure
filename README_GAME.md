# Braslav Grammar Adventure

This package contains one ready-to-run website with three English grammar games:

1. **Grammar Mines** — an 8×8 minesweeper game with flags, lives, scoring and grammar questions.
2. **Word Road: Braslav** — a three-lane arcade game with ten grammar missions.
3. **Hidden Grammar** — three hidden-object scenes with eight objects and grammar challenges in each scene.

## How to run

Open index.html in a modern browser. Keep mia.png, mines-cover.png and race-cover.png in the same folder as index.html.

Music starts after the first click because browsers block sound before user interaction. Progress is saved locally in the browser.

The `audio` folder contains separate looping tracks for all three games plus click, correct-answer, wrong-answer and explosion effects. Keep this folder beside `index.html`; all audio paths are already connected.

## Controls

- Grammar Mines: left click opens a tile; right click places a flag.
- Word Road: Left/Right arrows or A/D; on touchscreens tap the left or right half of the road.
- Hidden Grammar: click or tap objects; use Hint when needed.

All interface text and learning tasks are in English.
